# Sahil Singh — HTML & CSS Portfolio

A responsive personal portfolio built for the HTML & CSS internship submission.

## Files
- `index.html` — semantic HTML5 page and content
- `style.css` — all presentation and responsive rules
- `screenshots/desktop.png` — desktop design preview
- `screenshots/mobile.png` — mobile design preview

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome or Microsoft Edge.
3. For editing, open the folder in Visual Studio Code.

No JavaScript, React, Bootstrap, backend, or database is used by this portfolio website.

## Before submission
1. Replace `your.email@example.com`, `your-username` GitHub and LinkedIn placeholders in `index.html`.
2. Verify project descriptions and add repository/demo links only if they are public and working.
3. Open the site at desktop and mobile widths; test every navigation link.
4. If you change the design, recapture screenshots from your browser so they show the final version.

## Project description (submission form)
This is a responsive personal portfolio website built using HTML5 and CSS3. It introduces Sahil Singh, a B.Tech Computer Science and Engineering student at UIT RGPV, Bhopal, and presents his education, technical skills, and project experience. The website includes semantic sections, anchor-based navigation, project cards, hover and focus states, and responsive layouts using CSS Grid, Flexbox, and media queries. The contact area provides email and professional profile placeholders that can be replaced with verified public links.

## Notes
The project cards describe the user's FreshBite online food-ordering project and Savariya AI/ML backend work at a high level. The HTML/CSS portfolio itself contains no JavaScript.
